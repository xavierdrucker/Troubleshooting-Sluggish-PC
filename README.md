# Troubleshooting-Sluggish-PC

In this lab, a user reported that his computer was operating very slowly and that applications were opening very slowly during this demonstration. I will perform troubleshooting tasks to identify and resolve the problem. I will provide a solution at the end.

<h2>Environments and Technologies Used</h2>

- SpiceWorks (Help Desk Ticketing System)
- Remote Desktop (Mac OS)
- Windows settings
- Task Manager
- Network settings

<h2>Operating Systems Used </h2>

- Apple Mac OS 
- Windows 11 Pro </b> (25H2 ) (Virtual Machine)

Now, taking a look at the user's computer via RDP (Remote Desktop Protocol), I open up Task Manager to see what's the problem could be causing the end user's computer to operate very slowly,

<img width="2554" height="1243" alt="Screenshot 2026-09-03 at 5 43 22 PM" src="https://github.com/user-attachments/assets/2b6b43a4-eb16-4532-bbcb-6ff302d527bd" />

<h2> Conclusion </h2>


# The EndUser's Windows Computer was experiencing unusually high CPU utilization, resulting in slow system performance. RDP (Remote Desktop Protocol) into the end user's computer to end unnecessary tasks, causing high CPU usage.
